# 🏜️ Sahara & Co — Travel Planner

Plan trips across Morocco: explore cities, build itineraries on an interactive map, and estimate your budget.

## ✨ Features

- Explore Moroccan cities and destinations
- Build trip itineraries
- Interactive map (Leaflet)
- Budget estimation
- Responsive interface

## 🛠️ Tech Stack

- **Frontend:** React 19 · TypeScript · Vite · Tailwind CSS 4
- **Map:** Leaflet · react-leaflet
- **Routing:** react-router-dom
- **Backend / Data:** Supabase

## 🚀 Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal (usually http://localhost:5173).

Build for production:

```bash
npm run build
npm run preview
```

## 📁 Project structure

- `src/pages/` — app pages
- `src/components/` — reusable UI components
- `src/data/` — destinations and trip data
- `src/context/` · `src/lib/` · `src/utils/` — state, helpers and shared logic
- `public/images/` — images
- `docs/` — project documentation
