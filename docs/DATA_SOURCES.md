# Sources des données (prix indicatifs)

Tous les prix du site sont des **estimations indicatives en dirhams (MAD), par personne**. Ils changent selon la saison, la disponibilité, le groupe et la négociation. Dernière vérification : 15 octobre 2026.
Conversions utilisées pour comparer les sources : 1 EUR ≈ 10,9 MAD, 1 USD ≈ 9,5 MAD (approximations).

Note : la meilleure période (mars-mai et septembre-novembre) est une recommandation courante, non sourcée individuellement.
